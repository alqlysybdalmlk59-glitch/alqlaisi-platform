# لوحة إدارة الويب — منصة القليسي

واجهة إدارية عربية RTL متصلة بخادم FastAPI؛ ليست صورة ثابتة. تشمل نظرة عامة، المتاجر والبائعين، مراجعة المنتجات وتحديد سعر البيع، متابعة الطلبات والتوصيل، قائمة المستخدمين، تذاكر الدعم والإعدادات.

## التشغيل

1. شغّل الخادم حسب تعليمات `backend/README.md`.
2. شغّل واجهة الويب عبر خادم ملفات محلي من جذر المستودع:
   `python -m http.server 5500`
3. افتح `http://localhost:5500/admin_dashboard/`.
4. أدخل عنوان API، الافتراضي `http://localhost:8000/api`، ثم بيانات مدير معتمدة مسبقاً.
5. يجب أن يعيد `/api/auth/me` الدور `admin`. الواجهة لا تنشئ مديرين ولا تمنح الصلاحيات.

**تنبيه:** لا تستخدم HTTP غير المشفر عند النشر العام. انشر الواجهة خلف HTTPS، واضبط `CORS_ALLOW_ORIGINS` على أصل لوحة الإدارة فقط. رمز الدخول محفوظ في `sessionStorage` وينتهي عند إغلاق الجلسة، لكن يظل ضرورياً منع XSS وتأمين الاستضافة.
