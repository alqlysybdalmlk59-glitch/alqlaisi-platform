# منصة القليسي — بداية Flutter + Firebase Authentication

هذا مشروع بداية قابل للتشغيل بعد إعداد Firebase. يحتوي على:
- إنشاء حساب بالبريد وكلمة المرور.
- إرسال رابط تحقق للبريد الإلكتروني.
- منع الدخول إلى الصفحات المحمية قبل توثيق البريد.
- تسجيل الدخول والخروج.
- تسجيل الدخول بحساب Google.
- استعادة كلمة المرور.
- هيكل صفحات العميل، مع صفحات أولية واضحة لتوسعتها.

## قبل التشغيل
1. ثبّت Flutter وAndroid Studio.
2. أنشئ مشروعًا في Firebase Console.
3. فعّل Authentication > Sign-in method:
   - Email/Password
   - Google
4. اربط تطبيق Flutter بمشروع Firebase باستخدام FlutterFire CLI:
   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
   سيُنشئ الأمر الملف `lib/firebase_options.dart`. لا تنشئه يدويًا ولا ترفع بيانات إعداداتك الخاصة علنًا.
5. نفّذ:
   ```bash
   flutter pub get
   flutter run
   ```
6. لتسجيل الدخول بجوجل على Android: أضف SHA-1 وSHA-256 في إعدادات تطبيق Firebase ثم نزّل/حدّث إعدادات Android إذا طلب FlutterFire ذلك.
7. اختبر رابط توثيق البريد على جهاز حقيقي أو محاكي متصل بالإنترنت.

## تنبيه مهم
هذا المشروع يطبّق مصادقة حقيقية عبر Firebase Authentication، لكنه لا يحتوي بعد على خادم التجارة الإلكترونية أو قاعدة بيانات الطلبات والمنتجات أو صلاحيات الإدارة. لا تعتبر واجهة التطبيق وحدها حماية للبيانات. قبل الإنتاج، أضف Firestore/خادم API وقواعد صلاحيات موثوقة، وألزم الخادم بالتحقق من الدور والصلاحيات.
