# منصة القليسي للتجارة الإلكترونية (دليل التشغيل على نظام واندوز - Windows)

تم تهيئة وتطوير المنصة بالكامل لتعمل بسلاسة على نظام التشغيل **Windows (ويندوز)** مع الربط المباشر بين تطبيق الواجهة (Flutter Desktop) وخادم الخلفية المركزية (Python FastAPI Backend).

---

## 🚀 طرق التشغيل المتاحة على واندوز

### الطريقة الأولى: التشغيل الشامل بضغطة زر واحدة (موصى بها)
1. قم بفتح مجلد المشروع في واندوز.
2. انقر مزدوجاً على الملف: **`run_all.bat`**
3. سيقوم الملف تلقائياً بـ:
   - فتح نافذة لتشغيل خادم **FastAPI Backend** على العنوان `http://127.0.0.1:8000`.
   - فتح نافذة ثانية لتشغيل تطبيق **Flutter Windows Desktop**.

---

### الطريقة الثانية: التشغيل اليدوي خطوة بخطوة

#### الخطوة 1: تشغيل خادم الخلفية (Python FastAPI)
* قم بتشغيل الملف: **`run_backend.bat`**
* أو نفّذ الأوامر التالية من خلال موجه الأوامر (Command Prompt):
```cmd
pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```
* يمكنك فتح واجهة توثيق API وتجربة الخدمات عبر المتصفح على العنوان: `http://127.0.0.1:8000/docs`

#### الخطوة 2: تشغيل تطبيق Flutter على واندوز
* قم بتشغيل الملف: **`run_windows.bat`**
* أو نفّذ الأمر التالي في موجه الأوامر:
```cmd
flutter run -d windows
```

---

## 🌟 مميزات النظام المكتملة على واندوز

1. **الربط التلقائي والذكائي لمسار الخادم (Dynamic Base URL)**:
   - يتعرف التطبيق تلقائياً على بيئة التشغيل: عند التشغيل على واندوز أو الويب يتصل بـ `http://localhost:8000/api` وعند التشغيل على محاكي أندرويد يتصل بـ `http://10.0.2.2:8000/api`.
2. **مؤشر حالة الاتصال بالخادم (Connection Status Indicator)**:
   - يظهر أعلى التطبيق شريط يوضح حالة الاتصال بخادم FastAPI (أخضر عند الاتصال المباشر، وبرتقالي في وضع البيانات المحلية Offline).
3. **التغذية التلقائية لقاعدة البيانات (SQLite Auto-Seeding)**:
   - يتم إنشاء وحفظ قاعدة البيانات في المجلد `backend/alqulaisi.db` وتغذيتها بالمنتجات والمتاجر الافتراضية تلقائياً عند أول تشغيل.
4. **دعم البوابات الثلاث بمرونة**:
   - بوابة العميل (Client Portal): تصفح السلع، إضافة للسلة، الدفع عند الاستلام، ومتابعة الطلبات.
   - بوابة البائع (Vendor Portal): التحكم في توافر المنتجات واستلام وتحديث حالات الطلبات.
   - لوحة الإدارة (Admin Portal): اعتماد المتاجر وتحليلات المبيعات المدعومة بـ Gemini AI.
