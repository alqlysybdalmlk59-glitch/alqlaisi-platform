# خطة تنفيذ منصة القليسي متعددة البائعين (Alqlaisi Platform)

وصف شامل لبناء منصة التجارة الإلكترونية متعددة البائعين حسب المواصفات التفصيلية المقدمة (تطبيق العميل، تطبيق البائع، لوحة الإدارة، الصلاحيات، بدون نظام كميات مخزون، تقسيم الطلبات حسب البائع، والدفع عند الاستلام).

## Proposed Changes

### 1. نماذج البيانات والهياكل الأساسية (`com.alqulaisi.platform.data`)
- تحديث `Models.kt` لتشمل:
  - حالات الطلب الدقيقة: `PENDING` (بانتظار القبول), `ACCEPTED` (مقبولة/قيد التجهيز), `DELIVERING` (للتوصيل), `COMPLETED` (تم الاستلام), `CANCELLED` (ملغي).
  - حالات المنتج: `DRAFT`, `PENDING_REVIEW`, `PUBLISHED`, `REJECTED`, `UNAVAILABLE`.
  - نماذج البائع، العميل، الطلب المقسم حسب البائع، وتذاكر الدعم.

### 2. المستودع المركزي وإدارة الحالة (`EcommerceRepository.kt`)
- إدارة تدفقات الحالة (StateFlows) للمنتجات، الطلبات، المتاجر، السلة، وتذاكر الدعم.
- تطبيق قواعد العمل:
  - تقسيم الطلبات تلقائياً حسب البائع عند الدفع (Cash on Delivery).
  - عدم وجود نظام كميات مخزون (الحالة تعتمد على التوفر اليدوي: متاح / غير متاح).
  - التحقق الصارم من الصلاحيات وأدوار المستخدمين (عميل، بائع، إدارة).

### 3. واجهات تطبيق العميل (`ClientPortalScreen.kt`)
- الشاشة الرئيسية: تصفح المنتجات، البحث والتصفية حسب الفئة والسعر، حالة التوفر.
- تفاصيل المنتج: عرض تفاصيل المنتج، البائع، زر الإضافة للسلة والمفضلة.
- عربة التسوق: عرض العناصر، المجموع، رسوم التوصيل لكل بائع، تقسيم الطلبات.
- متابعة الطلبات: تتبع الحالات بدقة وتحديثاتها.
- الملف الشخصي والدعم: إدارة العناوين، الشكاوى، وتذاكر الدعم.

### 4. واجهات تطبيق البائع (`VendorPortalScreen.kt`)
- طلب فتح المتجر ومتابعة حالته (قيد المراجعة / مقبول / مرفوض).
- إدارة منتجات المتجر: إضافة/تعديل منتج، تحديد التوفر (متاح/غير متاح)، إرسال للمراجعة.
- الطلبات الواردة لمتجر البائع: قبول/رفض الطلب، تحديث حالة التجهيز.
- التقارير والمبيعات: ملخص المبيعات، الطلبات المكتملة، والعمولات.

### 5. واجهات لوحة التحكم للإدارة (`AdminPortalScreen.kt`)
- مراجعة طلبات فتح المتاجر والموافقة عليها/رفضها.
- مراجعة المنتجات المعلقة والموافقة عليها أو رفضها مع ملاحظات.
- إدارة الطلبات والتوصيل الداخلي.
- إدارة المستخدمين والصلاحيات.
- تقارير المنصة والعمولات.
- مساعد الذكاء الاصطناعي (Gemini AI) لتحليلات المبيعات ورؤى السوق.

## Verification Plan

### Automated Tests
- تجميع وبناء التطبيق باستخدام `gradle_build(commandLine = "app:assembleDebug")`.

### Manual Verification
- اختبار تسجيل الدخول والانتقال بين أدوار (عميل، بائع، إدارة).
- اختبار إضافة منتج من قبل البائع، مراجعته واعتماده من الإدارة، وعرضه في متجر العميل.
- اختبار سلة التسوق وتقسيم الطلبات والدفع عند الاستلام.
